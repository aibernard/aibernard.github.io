发布到GitHub

这里必须先明确一点：Hexo 项目源码仓库与 GitHub Pages 网站仓库，不一定是同一个仓库。

方式 A：通过 Hexo 自动部署到 gh-pages 分支

这种方式通常是：

  • main 分支：保存 Hexo 源码、文章、主题配置。
  • gh-pages 分支：保存生成的静态网站。
  • Hexo 的 hexo-deployer-git 插件负责把 public/ 发布到网站分支。

如果你当前使用的是这种方式，日常发布可以非常简单。
